Support

The activity stopped recording when the screen locked

Location permission needs to be Always, not While Using. With While Using, iOS suspends the app once the screen has been off for a while and the track ends there. Settings › Privacy & Security › Location Services › Waypath.

My distance is short, or the track cuts corners

GPS is worst exactly where running is most common: under trees, between tall buildings, in the first minute before the fix settles. Waypath smooths the track, which trims a little distance rather than inventing it. Starting outside and waiting for the accuracy indicator before you set off makes a visible difference.

The heatmap looks empty

It is built only from your own completed activities. One run is a line, not a heatmap; it starts telling you something after roughly ten. There is no community data feeding it.

Can I import a GPX route from somewhere else

Routes are drawn in the app in this version. If you need a specific import or export path, write and say which format — it is useful to know what people actually have.

Deleting a route or an activity

Swipe on the item in its list. Deletion is local and immediate, and there is nothing on a server to also delete, because there is no server.

Where is my data

On your iPhone. No account, no sign-in, no upload. Removing the app removes the history with it.
